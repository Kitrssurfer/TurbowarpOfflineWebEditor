# Turbowarp Offline Web Editor

A fully offline, browser-based version of TurboWarp packaged as a standalone HTML file. This project allows you to run the TurboWarp editor without an internet connection—ideal for classrooms, restricted networks, or portable use.

# Features
1. Runs entirely offline in your browser
2. No installation or setup required
3. Single HTML file for easy distribution
4. Preserves core TurboWarp functionality
5. Works on most modern browsers

# Use Cases
1. Offline coding environments (schools, workshops)
2. Portable Scratch/TurboWarp editor on USB drives
3. Backup editor when internet access is unavailable

# How to Use
1. Download the HTML file
2. Open it in your web browser
3. Start creating and editing projects instantly
